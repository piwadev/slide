# Credits

## 3D car models

The cars below use real 3D models made by other artists, shared under Creative Commons licences. Thank you!
All models were prepared for the game (wheels removed — the game draws its own customisable wheels — geometry simplified,
textures resized, compressed with meshopt) — see `scripts/models/`. Every model keeps its author's credit under the licence terms
(CC BY: attribution required; changes were made as described above). The licence text was read from the metadata embedded in the model files.

*Provenance note:* Sketchfab downloads need a login, so the Sketchfab models were taken from public GitHub repositories that redistribute the
original files unchanged; the author, title, source URL and licence were verified from the metadata Sketchfab embeds in each file. The Poly Pizza
models were downloaded from poly.pizza (licence shown on each model page). Models with NC / ND / SA licences or without licence data were not used.

Cars without a credit above (180SX/AE86 aside) — Silvia S15, RX-7 FD3S, Chaser JZX100, M3 E46, AMG C63 S, Charger Hellcat, 488 Pista, 720S, 240Z and the Hakosuka — still use the game's own procedural bodies.
