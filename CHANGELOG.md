# Changelog

## v1.1.0
- **Real car models.** The R34 GT-R V-Spec II, Supra A80, 180SX, AE86, Huracán EVO, 911 Turbo (930), Mustang Boss 302 and Challenger 1970 now use detailed 3D models (credits in CREDITS.md). The other 10 cars keep their procedural bodies.
- Customisation still works on the real models: paint colour, finishes (metallic/pearl/candy/chrome/colour-shift…), two-tone, liveries and stickers, window tint, headlight colour, underglow, exhaust flames, body-kit add-ons and every wheel option (the game's own wheels on four separate pivots for steering, spin and suspension).
- Model pipeline (`scripts/models/`), automatic fallback to the procedural body if a model fails to load.
- Renamed to match the models: Porsche 911 Turbo (930), Lamborghini Huracán EVO. Body dents (crash deformation) are only shown on procedural cars.
- New screenshots.

## v1.0.0
- First release of SLIDE: 18 cars, 6 maps, 30-event career, Free Roam / Drift Challenge / Time Attack / Tandem.
- Deep 3D garage customisation (body, wheels, paint, liveries, lights, performance, tuning).
- Drift scoring with combos, multipliers, near misses, clipping zones and tandem bonus.
- Windows launcher with automatic game updates from GitHub Releases and file-based saves in %APPDATA%\Slide.
